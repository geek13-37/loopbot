# LoopBot

Мини-игра про циклы. Есть робот на клетчатом поле, ему надо дойти до флажка и по пути собрать звёзды. Программу для него собираешь из блоков: вперёд, налево, направо, «повтори N раз» и «пока».

Делал под телефон, так что это PWA — можно добавить на главный экран и открывать без интернета.

## Что внутри

Три урока:

1. **Повтори N раз** — обычный цикл со счётчиком
2. **Цикл в цикле** — вложенные циклы
3. **Цикл «пока»** — цикл с условием

В каждом уроке сначала немного теории, потом пример (его можно запустить и посмотреть, какой блок сейчас выполняется), вопрос на понимание и задачи. В задачах есть лимит на количество блоков, так что просто накидать десять «вперёд» подряд не выйдет.

Пройденные уроки запоминаются в localStorage.

## Запуск

Нужен Node.js (у меня 26-й, на более старых не проверял).

```sh
npm install
npm run dev
```

Откроется на http://localhost:5173. Dev-сервер запущен с `--host`, поэтому с телефона в той же Wi-Fi сети можно зайти по IP компьютера — адрес Vite пишет в консоль.

Остальные команды:

```sh
npm test          # тесты интерпретатора
npm run build     # сборка в dist/
npm run preview   # посмотреть собранную версию
```

## Стек

React 19, TypeScript, Vite, Tailwind 4, zustand для прогресса, react-router, vite-plugin-pwa. Тесты на vitest.

## Структура

```
src/
  engine/       интерпретатор программ и логика поля
  content/      тексты уроков и карты уровней
  components/   поле, робот, редактор программы
  pages/        главная и страница урока
  store/        сохранение прогресса
```

### Как устроены карты

Уровни задаются массивом строк, один символ — одна клетка:

| символ | что это |
|---|---|
| `.` | пустая клетка |
| `#` | стена |
| `*` | звезда |
| `F` | финиш |
| `^` `>` `v` `<` | старт робота и куда он смотрит |

Например, `['>*.*.*F']` — коридор из семи клеток с тремя звёздами. Новый уровень добавляется в `src/content/lessons.ts`.
